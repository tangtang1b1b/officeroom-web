- 先看相鄰的現有程式碼,沿用它的命名、結構與寫法。
- 只改被指派的檔案;需要動到範圍外的檔案時,停下來回報,不要自己擴大。
- 改完用 `npx vitest run 2>&1 | tail -15` 或規劃書指定的方式確認沒壞;不要貼完整輸出。
- 完成後只回報(10 行內):改了哪些檔案、關鍵設計決定、需要注意的地方。不貼完整程式碼。
