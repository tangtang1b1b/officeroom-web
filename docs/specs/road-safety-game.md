# 重機道路安全判斷遊戲

## 目標

桌面瀏覽器單人風險教育遊戲。玩家以第一人稱在台灣風格的雙向山路跟隨慢車，接近右彎盲區後選擇等待、超車、煞車或返回原車道。遊戲不是駕駛訓練器，遊戲化速度、距離和結果不代表真實事故率。

## 流程與操作

- 流程：`menu → tutorial → playing → decision → finish / near_miss / collision → debrief → retry`；遊玩中可以暫停。接近盲彎前會暫停並展示跟車距離、前車速度、對向視線及車道位置，玩家可選擇保持車距等待或嘗試超車。超車選項依可用會車時間與估計超車時間啟用或停用。
- `W`／`↑` 加速；`S`／`↓` 煞車；`A`／`D` 或左右方向鍵平滑移動；`R` 用新情境重玩；`M` 切換音效；`Esc` 暫停或繼續。
- 同情境重試使用相同種子；換一組情境則生成新種子。
- 結算顯示事件時間軸、最小距離與本局替代策略。解說只根據當局事件，不作現實駕駛保證。

## 情境與判定

- 以固定步長更新玩家距離、速度、車道位置、前車和對向車；情境參數由可重播種子產生。記錄整局定頻軌跡，供外部視角回看，不改寫原始結果。
- 前車可在彎前減速但維持低速行進，避免無操作時必然追撞；對向車持續沿道路移動，彎道遮蔽以道路幾何與視線線段估算。等待策略保持原車道至對向車通過；超車策略需切出並在會車前返回。玩家位置、速度、煞車時機和車距決定碰撞、近失或通過結果。車流通過且玩家回到原車道後，於短距離內結束情境。
- 碰撞以簡化車距閾值判定，先播放短暫失衡與滑行，再顯示結果。事件記錄包含切出、前車減速、來車可見、煞車、返回、會車及結果。

## 場景與資產

- Three.js 僅於 client-side 元件載入，場景包含彎道道路、雙向中心線、護欄、植被、山壁、前車、箱型對向車與把手／儀表前景；騎乘相機掛在機車騎士視點 rig 上，眼點位於車身上方並隨車道位置移動，不放在完整車體中心。第一人稱機車模型維持約 2.15m 車長，按正確前進方向定位於騎士下方，呈現模型原有的前整流罩、把手與油箱；模型失敗時才顯示程序座艙，不補造模型未提供的零件。前車、路面及車道線需保留足夠視野，以建立切換車道時的相對距離感；左右移動限制在路面範圍內。轉向傾角隨輸入逐步累積並在放開後平順回正；機車本體朝轉向側傾斜，視角只朝轉向方向微幅左右轉動，不整個翻滾地平線。左轉左傾並微看左，右轉右傾並微看右；彎道曲率提供額外車身傾角。通過車輛離開玩家附近後隱藏；回顧可切換外部視角重播並顯示實際機車模型。
- 道路使用 Poly Haven Asphalt 01 的 1K diffuse 與 normal GL 紋理；Tahseen 的 Motorcycle GLB（CC BY 4.0）用於重播外部視角，F707 Mitsubishi Fuso Ecanter GLB（CC BY 4.0）作為前車，ElectroNick Dump Truck glTF（CC BY 4.0）作為對向車，車頭朝向須面向玩家。護欄、植被、岩石與 HDRI 等仍以程式生成幾何表示或尚未匯入。所有外部素材記錄於 `CREDITS.md`。
- 手機畫面提示建議使用桌面瀏覽器。

## 目前限制

重播外部視角、前車及對向車使用已授權的外部模型；多數環境仍是輕量程序幾何。道路使用 diffuse 與 normal 貼圖。其他環境模型與 HDRI 尚未匯入。場景未按真實道路尺寸、車輛性能或交通規範校準。
